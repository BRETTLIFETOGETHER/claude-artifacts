# Edition Converter

The platform rule: create once, configure many ways. Never fork the master — generate editions from it.

## Neutral master principle

Author, or identify, the master in neutral language first. Editions are overlays applied to that master, so the master must stay clean of audience-specific vocabulary. If the supplied piece is already slanted to one audience, extract the neutral master before converting.

## Five overlays (apply in this order)

1. Branding — organization identity
2. Audience — who is holding this edition
3. Values — secular / values-based / Christian / denominational / organization-specific
4. Content — swap examples, stories, and applications for the audience
5. Format — length, reading level, delivery format

## Church ↔ marketplace translation

Keep the formation architecture identical (structure, session counts, rhythm); translate vocabulary and outcomes:
- discipleship → development; congregation → team or company; ministry → mission or impact; stewardship → ownership or responsibility; small group → cohort or team huddle
- Church editions speak formation; corporate editions speak outcomes (culture, retention, leadership) while carrying the same spine

## Age editions — the content ladder

- Kids: wonder
- Teens: honesty and identity (write to a 14-year-old centerpoint)
- Adults: freedom and stewardship

Same truth at every rung; the ladder is the connective spine across a campaign's editions.

## Persona anchoring

Where audience character sheets exist (for example the "Stretched Provider": financially stressed mid-life married parents), write to that sheet's tone and situations. If no sheet exists for the target audience, draft a short character sheet first and confirm it before converting at volume.

## Alignment check before delivering

Editions of one master must keep matching structure — same session and day counts, same section order — so kits, brochures, and leader materials line up across the whole family of editions.
