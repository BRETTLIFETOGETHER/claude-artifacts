Two-minute setup

The site is already live. This connects the Generate buttons.

Checking…Asking the server whether a key is configured.
1

Claim the site

A Netlify Drop deploy starts out anonymous, which means it has no settings to change. Click Claim this site in the Netlify banner and sign in or create a free account. Nothing redeploys; the URL stays the same.

2

Get an API key

Go to console.anthropic.com, add a payment method, and create a key under API Keys. Generation here runs a few cents per document, not dollars.

3

Add the key to Netlify

In your Netlify site: Site configuration → Environment variables → Add a variable. Key: ANTHROPIC_API_KEY. Value: the key you just created. Leave the scope on all deploy contexts.

4

Redeploy

Functions read environment variables at deploy time, so the key needs one redeploy to take effect. Deploys → Trigger deploy → Deploy site, or simply drag the same zip onto the Drop page again.

5

Test it

Reload this page. The banner above should turn green. Then open the platform and press any Generate button.

Open the platform

Two things worth knowing

Your key never reaches the browser. The app posts prompts to /api/generate, and the function adds the key on the server. Anyone viewing source sees no credentials.

Everything else already works without a key. The family profile, the relationship map and computed scores, all 225 journeys, the 125 tools, the 12 discernment sliders, the calendar and its .ics export — none of those call the model. Only the Generate buttons need step 3.

Custom domain: Netlify → Domain management → Add a domain. Point christianadvisornetwork.com at the records Netlify shows you.
