# COACHING SESSION TITLES — AS FILMED

Twenty-four sessions. Every title below is what was actually said on camera, with
the verbatim quote so it can be checked against the transcript. Nothing proposed,
nothing invented.

**Three levels of coverage**

- **TITLE** — Brett names it as a title on camera. "It's called…" / "The title of
  this one is…" / "The topic of this one is…"
- **TOPIC** — Brett names the subject but does not frame it as a title.
- **NOT NAMED** — no session-level naming spoken at all.

# WHAT THIS SURFACES

**Next Generation is ready.** Six spoken titles, six spoken subtitles, all
consistent with each other and with the series name. Nothing needs deciding.

**Clarity has no titles at all.** Four sessions carry a "clarifying the…" phrase
that functions as a title, and two have nothing. Sessions 1 and 5 need naming
from scratch. This is also the title with the strongest source and the front-door
position, so it is the most consequential gap.

**Alignment names the acrostic once, in Session 3.** A viewer starting anywhere
else never learns that FAMILY is an acrostic. If these ship as standalone
modules, five of six sessions are missing the organizing idea.

**Meetings confirms the three-way conflict on Session 3.** Spoken singular,
script header plural, script contents page different again.

**Two on-camera numbering errors in Clarity.** Session 4 is called "the second
one." Session 5 asks Tom for "the four areas" where the framework has five.

**The series name is not stable.** Across the twenty-four sessions Brett says
"Family Legacy Coaching by Design," "Family Legacy by Design," "Family Legacy
Coaching," and once "Family Legacy, Coaching by Design." Four variants.
