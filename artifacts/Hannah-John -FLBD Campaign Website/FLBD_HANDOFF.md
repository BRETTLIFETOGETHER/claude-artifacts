## HARD-WON LESSONS (do not repeat)

1. **Always verify every page after structural edits, not just the one edited.** Cutting a section once removed the closing `</body>`/`</html>` and all four script tags — the homepage went blank.
2. **After any file-ending rebuild, check for empty containers.** Five inline renderers were silently lost (Five Areas, library grid, domains card, 40-day tracker, both Pricing book rows). The sweep: find elements with an id, no children, no text, and width > 50.
3. **Never anchor an inserted script to a string that may not exist** (`FLobserve()` was gone; the play button silently did nothing).
4. **Test real interaction, not markup presence.** Use a real mouse drag for sliders — synthetic events pass when the feature is broken.
5. **Watch for duplicate IDs** — `#crow` appeared twice on Pricing, so only the first filled.
6. **Editing by string offsets duplicated the entire top of the homepage once.** Split into whole blocks instead.
