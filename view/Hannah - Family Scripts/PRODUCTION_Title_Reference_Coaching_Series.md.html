KNOWN DISCREPANCIES IN THE SOURCE FILES

Production will encounter these when opening the script files. In every case the version in this document is correct.

Book 1, book subtitle. The script title block reads Building a Multi-Generational Legacy That Lasts. Use the version above.

Book 1, Session 3. The script's contents page reads "Helping Clients Clarifying Values and Priorities." The session header reads "Clarify." Use "Clarify."

Book 3, header line. The script's first line reads BOOK 3 - ALIGNMENT - FAMILY/BALTIC. Unexplained. Do not reproduce.

Book 4, book title. The script title line reads Alignment in Action Leading Conversations That Matter. Book 3's title has been concatenated onto Book 4's. Use Leading Conversations That Matter.

Book 4, Session 5. The script's contents page reads Facilitating Family Conversations. The session header reads Facilitating Family Dialogue. Use Facilitating Family Conversations.

Book 5, Session 3. The script's contents page reads Leading Meaningful Conversations / Facilitating with Clarity and Confidence. The session header inverts both verbs, reading Facilitating Meaningful Conversations / Leading with Clarity and Confidence. Use the contents page version.

ON-CAMERA NOTES

Books 2, 3, 5, and 6 are filmed. Books 1 and 4 are not.

Of the twenty-four filmed sessions, seventeen titles and two subtitles were spoken aloud. Everything else exists only on the page and can be changed without re-recording.

One place where the film disagrees with this document. Book 5, Session 3. On camera the phrase used is "Facilitating Meaningful Conversation," matching the script header rather than the contents page. It is said in passing mid-sentence, not as a title card, so it should be recoverable in the edit.
