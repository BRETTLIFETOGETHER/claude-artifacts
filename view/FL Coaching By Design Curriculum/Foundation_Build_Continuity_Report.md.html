Repeats. James 1:19 appears twice, in Sessions 2 and 5. This is inherited from the scripts, where Tom quotes it in both sessions in different lengths. It is handled deliberately: Session 2 uses the short form, Session 5 takes it whole including the third clause and opens with a line acknowledging the earlier appearance. No other verse repeats.

Recommendations rather than sourced. Three items: - Proverbs 20:5 as the Session 2 key verse. Tom quotes it in the script but the script gives no key verse. Recommended over James 1:19 to avoid a doubled key verse. - Philippians 2:1-4 in Session 4. The script quotes Philippians 2:2 only. Expanded to the fuller passage for the Going Deeper questions. - Ecclesiastes 2:18-21 in Session 1. The Legend cites 2:18-19. Verse 21 added because the Coaching Book quotes it directly.

Translation. All quotations are set in NIV, per the recommended default. This remains unconfirmed and is blocking for layout. The Coaching Book and Family Book both state NASB, so the companion readings will show a different translation unless the note is added to the copyright page.

Passages are cited rather than reproduced in Going Deeper. Full text gets set at layout under the translation permission grant. Only the key verses carry text, in short form.

The Session 2 tool uses the four essential skills as a self-scoring instrument. The four skills are sourced. The scoring method is not, and is labeled as such.
